    信息检索功能¶

    本页面详细介绍TG-FF资源管理助手v3.0.0的信息检索功能。此功能可以灵活选择对话，关键词、时间等筛选条件，能快速检索想要的信息。

    功能说明¶

    信息检索功能为用户提供强大的搜索能力，可以根据多种条件在Telegram对话中查找特定消息，从而快速定位所需的信息。无论是查找历史讨论内容、重要通知还是特定媒体资源，都能迅速精准地完成。

    界面布局¶

    信息检索模块的界面主要包含以下几个部分：

    1. 对话选择区 - 选择需要搜索的对话来源
    2. 搜索条件设置区 - 设置关键词、时间范围等筛选条件
    3. 搜索结果显示区 - 以列表形式展示符合条件的消息
    4. 消息详情显示区 - 查看选中消息的详细内容和上下文

    使用步骤¶

    1. 选择搜索对话¶

    1. 在"对话选择"下拉菜单中，浏览并选择需要搜索的对话
    2. 可以选择个人聊天、群组或频道
    3. 也可以选择"所有对话"选项，在全部对话中进行搜索
    4. 选择完成后，对话名称将显示在选择框中

    2. 设置搜索条件¶

    关键词搜索¶

    1. 在"关键词"输入框中输入需要搜索的关键词或词组
    2. 支持多个关键词组合搜索，用空格分隔
    3. 可以使用引号包围词组进行精确匹配，如"重要通知"

    时间范围筛选¶

    1. 点击"开始日期"和"结束日期"选择器
    2. 设置需要搜索的消息的时间范围
    3. 只有在指定时间范围内的消息才会被包含在搜索结果中

    消息类型筛选¶

    1. 在"消息类型"选项中，选择需要搜索的消息类型：
    2. 所有类型：搜索所有类型的消息
    3. 文本消息：只搜索纯文本消息
    4. 媒体消息：只搜索包含媒体(图片、视频等)的消息
    5. 链接消息：只搜索包含链接的消息
    6. 文件消息：只搜索包含文件附件的消息

    发送者筛选¶

    1. 在"发送者"输入框中，输入特定发送者的用户名或ID
    2. 只搜索由指定发送者发送的消息
    3. 留空则搜索所有发送者的消息

    3. 执行搜索¶

    1. 完成上述搜索条件设置后，点击"搜索"按钮
    2. 系统将根据设定的条件在选定的对话中进行搜索
    3. 搜索进度将在界面中显示
    4. 搜索完成后，结果将显示在搜索结果列表中

    4. 浏览搜索结果¶

    1. 搜索结果以列表形式显示，包含消息预览、发送者、发送时间等信息
    2. 关键词将在结果中高亮显示，便于快速识别
    3. 点击任意结果项可在右侧详情区查看完整消息内容
    4. 使用上下翻页按钮或滚动条浏览更多结果

    5. 查看消息详情¶

    1. 选中搜索结果中的任意消息后，右侧详情区将显示：
    2. 完整的消息内容
    3. 发送者信息
    4. 发送时间详情
    5. 媒体预览（如果消息包含媒体）
    6. 消息上下文（前后几条消息）

    6. 高级操作¶

    1. 点击"导出结果"按钮可将搜索结果导出为文本或CSV文件
    2. 点击"跳转到原对话"按钮可直接跳转到Telegram中的原始消息位置
    3. 点击"保存搜索"按钮可保存当前搜索条件，方便下次快速执行相同的搜索

    高级搜索技巧¶

    复合条件搜索¶

    1. 同时使用多个搜索条件可以更精确地定位信息
    2. 例如：特定时间范围内、特定发送者发送的、包含特定关键词的媒体消息

    正则表达式搜索¶

    1. 在高级设置中启用"使用正则表达式"选项
    2. 在关键词字段中输入符合正则表达式语法的搜索模式
    3. 例如：\d{4}-\d{2}-\d{2}可以搜索日期格式如"2023-05-28"的内容

    搜索结果过滤¶

    1. 在搜索结果显示后，可以使用"结果过滤"功能进一步筛选
    2. 在结果过滤框中输入新的关键词，实时过滤当前搜索结果
    3. 这对于在大量搜索结果中快速定位特定内容非常有用

    使用场景¶

    历史信息查找¶

    1. 查找过去讨论过的特定话题或决策
    2. 通过关键词和时间范围快速定位相关消息
    3. 避免重复讨论或确认历史结论

    资源内容检索¶

    1. 查找共享过的特定类型的媒体或文件
    2. 使用文件名关键词搜索特定文档
    3. 快速找到之前分享的重要资源

    专题内容整理¶

    1. 搜索特定主题的所有相关讨论
    2. 导出搜索结果，整理成专题资料
    3. 帮助团队知识管理和内容沉淀

    注意事项¶

    • 索引构建：首次搜索特定对话时，系统需要建立索引，可能需要一些时间
    • 搜索范围：大型群组的全文搜索可能需要较长时间，建议适当缩小搜索范围
    • 搜索精度：使用更具体的关键词和条件组合可以提高搜索精度
    • 资源占用：复杂搜索可能占用较多系统资源，请在资源充足的设备上使用
    • 隐私保护：搜索功能只能搜索您有权访问的对话内容

    常见问题解答¶

    Q: 搜索功能会将我的聊天内容上传到服务器吗？ A: 不会。TG-FF的搜索功能完全在本地进行，不会将您的对话内容上传到任何第三方服务器，充分保护您的隐私。

    Q: 为什么有些消息无法被搜索到？ A: 可能的原因包括：1) 消息内容是图片中的文字而非文本；2) 消息已被删除；3) 消息在您加入群组前发送且群组未保存完整历史记录。

    Q: 如何搜索特定时间段内的所有媒体文件？ A: 设置所需的时间范围，在消息类型中选择"媒体消息"，然后执行搜索，无需输入关键词。

    Q: 搜索结果可以保存或分享吗？ A: 是的，您可以使用"导出结果"功能将搜索结果导出为文本或CSV文件，然后保存或分享给他人。
