    文本发送功能¶

    本页面详细介绍TG-FF资源管理助手v3.0.0的文本发送功能。此功能可以将准备好的文本转发到指定的对话，可以设置转发频率，转发规则。

    功能说明¶

    文本发送功能允许用户将准备好的文本内容按照设定的频率和规则自动发送到指定的对话中，适用于需要定期发送固定内容或批量发送文本信息的场景。

    界面布局¶

    文本发送模块的界面主要包含以下几个部分：

    1. 文本编辑区 - 输入或导入需要发送的文本内容
    2. 目标对话选择区 - 选择文本将被发送到的目标对话
    3. 发送规则设置区 - 设置发送频率和方式
    4. 操作控制区 - 包含开始/停止发送按钮和状态显示

    使用步骤¶

    1. 准备文本内容¶

    直接输入文本¶

    1. 在左侧文本编辑框中直接输入需要发送的文本内容
    2. 每行文本将被视为一条独立的消息
    3. 可以包含表情符号、链接和简单格式标记

    导入文本文件¶

    1. 点击"导入文本"按钮
    2. 在弹出的文件选择对话框中，选择包含文本内容的TXT文件
    3. 点击"打开"，文件中的内容将被载入到文本编辑框

    2. 选择目标对话¶

    1. 在"目标对话"下拉菜单中，浏览并选择文本将被发送到的对话
    2. 确保您在目标对话中拥有发送消息的权限
    3. 选择完成后，目标对话名称将显示在选择框中

    3. 设置发送规则¶

    发送间隔设置¶

    1. 在"发送间隔"输入框中设置两条消息之间的时间间隔（秒）
    2. 建议设置适当的间隔，避免过于频繁触发Telegram的限制

    发送顺序设置¶

    1. 在"发送顺序"选项中选择：
    2. 顺序发送：按照文本在编辑框中的顺序依次发送
    3. 随机发送：随机选择文本内容发送，避免重复性

    循环模式设置¶

    1. 在"循环模式"选项中选择：
    2. 单次发送：将所有文本发送一遍后停止
    3. 循环发送：发送完所有文本后从头开始再次发送
    4. 指定次数：设置循环发送的次数

    4. 开始发送¶

    1. 完成上述设置后，点击"开始发送"按钮
    2. 系统将根据设置的规则开始发送文本消息
    3. 当前发送状态和进度将在状态区域显示

    5. 停止发送¶

    1. 如需停止发送，点击"停止发送"按钮
    2. 发送任务将立即停止，不再发送新的消息

    高级设置¶

    发送时段设置¶

    1. 点击"高级设置"展开更多选项
    2. 在"发送时段"部分，设置允许发送消息的时间范围
    3. 可以设置多个时间段，例如工作时间或低峰时段
    4. 系统将只在设定的时间段内发送消息

    消息格式设置¶

    1. 在"消息格式"选项中选择：
    2. 纯文本：以纯文本形式发送消息
    3. Markdown：支持Markdown格式的消息
    4. HTML：支持HTML标签格式的消息

    发送延迟变化¶

    1. 设置"随机延迟"选项，在基础发送间隔上增加随机延迟
    2. 这可以使发送行为更自然，减少被系统识别为自动发送的可能性

    使用场景¶

    定期通知发送¶

    1. 设置固定格式的通知文本
    2. 定期自动发送到群组或频道
    3. 适合发送日常提醒、工作安排等固定内容

    课程内容推送¶

    1. 准备课程或培训内容的文本
    2. 按照合理间隔发送到学习群组
    3. 自动完成教学内容的推送

    社群互动管理¶

    1. 准备一系列互动话题或问题
    2. 定期发送到社群中促进讨论
    3. 保持群组活跃度和参与度

    注意事项¶

    • 发送频率：过高的发送频率可能触发Telegram的限制机制，建议设置合理的发送间隔
    • 内容合规：确保发送的内容符合Telegram的服务条款和目标群组的规则
    • 用户体验：考虑接收方的用户体验，避免频繁打扰或发送过多信息
    • 权限要求：确保在目标对话中拥有发送消息的权限
    • 软件运行：文本发送功能仅在软件运行时有效，关闭软件后将停止发送

    常见问题解答¶

    Q: 如何避免被Telegram识别为垃圾消息发送者？ A: 设置合理的发送间隔（建议至少3-5秒），开启随机延迟，避免发送大量重复内容，确保内容有实际价值。

    Q: 可以同时向多个对话发送相同的文本吗？ A: 当前版本一次只能选择一个目标对话。如需向多个对话发送，需要设置多个单独的发送任务。

    Q: 支持发送带格式的文本吗？ A: 是的，可以在高级设置中选择Markdown或HTML格式模式，支持发送带格式的文本，包括粗体、斜体、链接等。

    Q: 如何在文本中添加变量，如日期、时间等？ A: 当前版本支持基本的变量替换，在文本中使用特定标记（如{date}、{time}）可以在发送时自动替换为当前日期和时间。
