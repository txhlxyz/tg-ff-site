    核心功能¶

    TG-FF是一款功能强大的飞机(Telegram)资源管理工具，专为解决飞机无法保存图片视频的问题而设计。

    突破下载限制

    • 突破禁止保存限制：轻松下载飞机群组和频道中设置了"禁止保存媒体"的内容
    • 灰色图标下载：支持下载显示灰色下载图标的受保护媒体文件
    • 批量下载支持：一次性下载大量受保护媒体，提高效率
    • 多格式支持：支持图片、视频、文件等多种媒体类型的下载

    智能资源管理

    • 自动分类：根据媒体类型自动分类存储下载内容
    • 批量处理：支持批量重命名、移动、删除等操作
    • 搜索功能：快速查找已下载的媒体文件
    • 导出功能：支持将媒体文件导出到指定位置

    高级功能

    • 定时下载：设置定时任务，自动下载新内容
    • 过滤条件：根据文件类型、大小、时间等条件筛选下载内容
    • 断点续传：支持大文件断点续传，确保下载可靠性
    • 多账号支持：支持同时管理多个飞机账号的资源

    功能模块¶

    全方位的资源管理与下载体验

    download 普通下载

    轻松浏览和下载Telegram对话中的媒体文件，支持图片、视频等多种格式。

    collections 批量下载

    大规模获取历史消息中的媒体文件，支持多种筛选条件。

    settings_suggest 自动下载

    实时监听新消息，自动下载符合条件的媒体内容。

    swap_horiz 消息转发

    自动将源对话的消息转发到目标对话，实现消息同步。

    edit_note 文本发送

    按设定频率和规则自动发送文本消息到指定对话。

    cloud_upload 资源发送

    将本地媒体文件与文本结合发送到指定对话。

    description 批量转文

    将图片批量转换为自媒体平台兼容的docx文档。

    search 信息检索

    快速搜索和筛选Telegram对话中的消息内容。
