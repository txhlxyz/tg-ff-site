    网络连接常见问题¶

    TG-FF 是一款 Telegram 文件下载辅助工具，软件运行时需要直接连接 Telegram 官方服务器。 由于网络限制，TG-FF 必须通过代理才能正常连接 Telegram 服务。如果你遇到"连接失败""无法登录"等问题，请参考以下 FAQ。

    网络连接基础问题¶

    ❓Q1：为什么 TG-FF 要使用代理才能工作？¶

    TG-FF 使用 Telegram 官方接口直连服务器，这种连接在很多地区是被限制的。 所以你必须配置代理（如 SOCKS5 或 MTProto），才能让 TG-FF 成功连接。

    ❓Q2：我已经连接了 VPN，为什么 TG-FF 仍然提示无法连接？¶

    很多 VPN 工具（尤其是厂家自带的 VPN 客户端）可能不会提供本地代理端口，TG-FF 无法识别 VPN 状态，因此仍然连接失败。

    你需要确认你的 VPN 是否支持"本地代理端口"，如下：

    工具名称 是否支持代理 常见端口
    Clash / Clash Verge / Meta ✅ 是 7890（SOCKS5）7897（HTTP）
    V2RayN / V2RayU ✅ 是 1080
    Shadowsocks / SSR ✅ 是 1080
    Surge ✅ 是 自定义
    蓝灯 / XX-Net / 企业定制 VPN ❌ 不一定 不支持
    OpenVPN GUI / L2TP / PPTP ❌ 否 不支持

    ✅ 如果你的 VPN 不支持 SOCKS5 代理端口，请切换为上表中支持的代理工具，如 Clash、V2RayN 等。

    ❓Q3：我设置了代理但依然无法连接，怎么办？¶

    请逐一排查以下问题：

    1. 你的代理工具是否运行中？
    2. 设置项是否正确（如：SOCKS5，127.0.0.1:7890）？
    3. 是否设置了用户名/密码？（如需认证，请填写）
    4. 是否被防火墙阻止了端口连接？
    5. 代理软件是否允许本地连接（如 Clash 中启用 Allow LAN）？

    你也可以通过命令验证代理：

    curl --socks5 127.0.0.1:7890 https://api.telegram.org

    如返回 JSON 内容，则代理可用。

    推荐代理方案¶

    ❓Q4：我不懂这些设置，是否能推荐一个"开箱即用"的方案？¶

    当然可以，以下是推荐的简单方法：

    安装 Clash Verge¶

    • 下载地址：https://github.com/zzzgydi/clash-verge/releases
    • 安装后导入订阅链接（你购买代理服务时提供）

    什么是订阅链接？如何获取？¶

    订阅链接是代理服务商提供的配置地址，一般长这样：

    https://sub.example.com/link/xxxxxxxx

    获取方法：

    1. 登录你的代理服务后台
    2. 找到「订阅链接」「Clash 配置」等字样
    3. 复制链接，在 Clash Verge 中点击「配置 → 添加订阅」粘贴进去即可

    在 TG-FF 中设置如下：¶

    代理类型：SOCKS5
地址：127.0.0.1
端口：7890
用户名/密码：空（如无认证）

    点击测试连接，显示成功即完成设置。

    正确使用建议¶

    为了保证你能够稳定、安全地使用 TG-FF，我们强烈建议你遵守以下几点使用规则，避免因为误操作或滥用而导致 Telegram 账号被限流或功能异常。

    1、不要频繁更换 VPN 类型或客户端¶

    • TG-FF 在启动时会使用你设置的代理连接 Telegram，一旦更换 VPN 类型或代理方式，连接稳定性将受到影响；
    • 尤其是从一个不支持 SOCKS5 的 VPN 切换到另一个，TG-FF 会无法连接；
    • 如果你使用的是支持本地代理（如 Clash）的工具，那么 VPN 怎么换都没关系。

    ✅ 建议：选择一个稳定的代理方案配置好后就不要频繁变更。

    2、不要频繁退出登录 Telegram¶

    • TG-FF 使用 Telegram 的授权登录机制，一次登录后凭证会保存在本地；
    • 没有必要每次启动 TG-FF 都重新登录 Telegram；
    • 频繁登录/登出可能导致 Telegram 对你的设备行为产生怀疑，甚至要求重新验证（验证码、人脸、电话验证等）。

    ✅ 建议：只要设备未重装系统、不清除 TG-FF 数据，就不需要重复登录。

    3、不要集中下载大量文件¶

    TG-FF 使用 Telegram 官方的API进行文件下载，底层机制与 Telegram 原生客户端相同，但 Telegram 对下载行为存在一定的风控策略。

    Telegram 官方的已知限制机制：¶

    风控类型 描述
    高频下载限速 短时间内请求大量文件，Telegram 可能自动限速（如降到几十 KB/s）；
    持续下载行为检测 长时间维持下载状态会被判定为非正常使用，有可能触发限流；
    大体积资源警戒 如果你持续下载大量超过 20MB 的文件，可能被 Telegram 限制下载带宽；
    异常访问频率 快速重复请求文件、切换 VPN、频繁更换网络也容易被系统标记；
    账号行为不一致 同时登录、批量下载、登录/登出操作混杂，会增加风控风险。

    TG-FF 的下载保护机制：¶

    TG-FF 内置了最大同时并发下载数量为 5 的限制，并自动排队控制下载节奏，尽量模拟正常用户使用行为，降低触发 Telegram 限制的可能性。

    建议使用方式：¶

    • 单次下载任务的总大小建议控制在 500MB ~ 1GB 以下为宜；
    • 下载过程尽量自然分布，不要长时间连续下载多个大文件；
    • 如果你需要下载多个视频、音频、文档，建议分批进行；
    • 避免同时进行大批量下载 + 切换代理 + 登出登录等高风险组合操作；
    • 出现速度骤降、连接中断、文件卡住等情况时，可能已被限速，建议暂停使用 30 分钟至数小时后再尝试。

    重要提醒¶

    📌 温馨提醒：

    虽然 TG-FF 已在客户端做了控制，但如果你自身的行为过于频繁或异常，Telegram 依然有可能对你的账号进行风控（如限速、验证码验证等）。

    总结一句话：¶

    TG-FF 不能自动"识别 VPN"，你必须配置一个明确的本地代理（SOCKS5）端口地址，或者使用官方的MTProto代理，软件才可以连接 Telegram。
