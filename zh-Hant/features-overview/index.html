    TG-FF V3 核心功能概览¶

    ## 1. 普通下载
    ![普通下载](../assets/images/pt1.png){ width=200 } - 选择对话查看所有媒体资源 - 支持单个或批量选择下载 - 时间筛选查询功能 - 支持下载显示灰色图标的媒体文件
    ## 2. 批量下载
    ![批量下载](../assets/images/bt1.png){ width=200 } - 大规模批量下载历史消息中的媒体文件 - 支持多种筛选条件（关键词、时间范围等） - 支持设置高级下载参数
    ## 3. 批量转文
    ![批量转文](../assets/images/bt2.png){ width=200 } - 图片批量转换docx文档 - 支持多种自媒体平台排版风格 - 一键生成，快速发布
    ## 4. 消息转发
    ![消息转发](../assets/images/at2.png){ width=200 } - 实时监听消息并自动转发 - 支持消息类型筛选 - 关键词和发送者筛选
    ## 5. 自动下载
    ![自动下载](../assets/images/at1.png){ width=200 } - 实时监听新消息并自动下载 - 多种筛选条件（媒体类型、关键词等） - 自动分类和通知设置
    ## 6. 文本发送
    ![文本发送](../assets/images/s1.png){ width=200 } - 文本批量自动发送 - 自定义发送间隔和顺序 - 支持多种发送模式和格式
    ## 7. 资源发送
    ![资源发送](../assets/images/s2.png){ width=200 } - 本地媒体资源批量发送 - 支持文本与媒体混合发送 - 支持多种文件格式
    ## 8. 信息检索
    ![信息检索](../assets/images/x1.png){ width=200 } - 强大的全文搜索功能 - 多种筛选条件组合 - 搜索结果导出功能
    ## 9. 消息链接下载
    ![消息链接下载](../assets/images/link.png){ width=200 } - 支持普通消息链接和评论链接 - 批量处理多个链接 - 自动识别链接中的媒体资源
